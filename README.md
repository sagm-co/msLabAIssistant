# Identificands

Identificands is a Python-based software platform that integrates inference models for multiple identification properties, applying them to compound identification through suspect and non-target screening approaches.

This repository provides:

1. Datasets and Jupyter notebooks supporting the ML models developed for the QuEChERS–HPLC–ESI–HRMS workflow. These include models for retention time inference (XGBoost), methodological amenability (Random Forest), probability prediction of protonated or deprotonated species (Random Forest), and chromatographic signal quality assessment (Random Forest). Each notebook documents its respective training set.

2. The *Identificands* source code, which integrates these inference models to predict identification properties and applies them to suspect screening (SS), and non-target screening (NTS). The platform processes `.raw` files generated by HPLC-ESI-HRMS (Orbitrap) following a QuEChERS sample preparation method.
